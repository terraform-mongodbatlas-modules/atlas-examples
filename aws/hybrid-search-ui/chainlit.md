# MongoDB AI risk

Click **Upload documents** or the composer **Ingest** button, then try a starter question. After ingest, use the composer **Demo** button to show the questions again.

Open **Chat Settings** (gear icon) to toggle **Keyword search**, **Vector search**, and **LLM answer** per session. Turn **LLM answer** off to see ranked chunk hits without an LLM API key. Keyword and vector toggles still run Atlas Search, Vector Search, or fused `$rankFusion` retrieval.
